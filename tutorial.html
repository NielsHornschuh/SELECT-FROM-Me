Lees de query en de statements

Lees eerst wat de query vraagt. Elk statement heeft een eigen taak:

SELECTwelke kolommen je nodig hebt
FROMuit welke tabel je gegevens haalt
WHEREwelke rijen aan een voorwaarde voldoen
ANDeen extra voorwaarde toevoegt
JOIN ... ONgegevens uit twee tabellen koppelt
SELECT naam FROM studenten WHERE klas = D1A;

03

Filter de rijen

Bij WHERE zoek je alleen rijen die aan een voorwaarde voldoen. Gebruik het vakje links van een rij om de hele rij te kiezen.

WHERE niveau = gevorderd;
